# Iceberg 学習ハンズオン

Icebergは未経験だが、データ基盤の経験は多少ある人が、Icebergを使った設計・運用に**上流工程から**参画できるようになるための日本語教材です。Icebergのスペシャリストになることは目指していません。

- 用語の解説を並べるのではなく、架空の小売チェーンの担当者が現場で困りごとにぶつかっていく物語として進めます
- 手を動かして確かめた内容だけを書きます（確認していないことは明記します）
- 学習中に詰まりやすい疑問は「よくある疑問」にまとめます

## 読み方

### コンテナで見る

```bash
docker compose up --build
# http://localhost:8080 を開く
```

### 開発モード（Node.js 18以上）

```bash
npm install
npm run docs:dev
```
